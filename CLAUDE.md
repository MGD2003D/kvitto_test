# CLAUDE.md

## Project Overview

Payments API for online schools: tariffs, payments with promo codes and installments, bank webhooks.
Layered architecture with FastAPI, SQLAlchemy, Pydantic and Alembic. Requirements live in `SPEC.md`.

## Architecture Rules

- **Endpoints are thin.** Handlers in `app/api/` parse input through schemas, call a service and return the response. No business logic in routes.
- **Business logic lives in services.** `app/services/` holds all domain logic (amounts, discounts, installment schedules, status transitions). Services import neither FastAPI nor SQLAlchemy and are testable in isolation.
- **Repositories own data access.** All ORM calls go through `app/repositories/`. No ORM queries anywhere else.
- **Schemas are not models.** `app/schemas/` (Pydantic) is the API contract, `app/models/` (SQLAlchemy) is the database. They change independently.
- **`main.py` is wiring only:** routers, lifespan, exception handlers.

## Directory Conventions

- One file per domain entity in models, schemas, services and repositories (`payment.py`, `payment_service.py`, `payment_repo.py`).
- Tests mirror the source: `tests/unit/` for services, `tests/integration/` for API and database.
- Migrations in `migrations/` (Alembic).

## Tech Stack

- Python 3.11+, FastAPI + Uvicorn
- SQLAlchemy 2.0 async (asyncpg in Docker, aiosqlite in tests) + Alembic
- Pydantic v2 (schemas and settings via pydantic-settings)
- pytest + httpx + pytest-asyncio
- ruff, Docker Compose, GitHub Actions

## Commands

Use `uv` and the `Makefile`. Don't suggest `pip` or call tools directly.

```
make install             # uv sync --locked (fails if uv.lock is stale)
make dev                 # uvicorn --reload
make test                # all tests
make test-unit           # services only
make test-integration    # API and DB only
make lint                # ruff check + format check
make fmt                 # ruff format + safe fixes
make migrate             # alembic upgrade head
make migration m="..."   # autogenerated revision — always review the file
make up                  # docker compose up -d --build
make down                # docker compose down
```

## Code Style

- Type hints on all function signatures.
- `async` for I/O: endpoints and repositories; pure functions stay sync.

## Key Principles

- Start minimal: don't add layers or abstractions until they're needed.
- Tests check results (response body, database state), not just status codes.
- If `SPEC.md` doesn't cover something, ask instead of guessing. Record each decision in `ASSUMPTIONS.md`
  (format: "ТЗ / Сделано / В проде (если отличается)") and update `SPEC.md` to match. The README only links to `ASSUMPTIONS.md`.

## Gotchas

- **Money:** IMPORTANT — every amount is an `int` in kopecks, in the API and in the database. No `float` anywhere, including intermediate calculations. Percentages use integer math: `price * percent // 100`.
- **Transactional boundary:** `commit()` happens only in the session dependency (`app/core/database.get_db`), which rolls back on exception. Repositories call `flush()` only.
- **Schema source of truth:** Alembic owns the schema. Never call `Base.metadata.create_all` in app code; test fixtures may. In Docker the entrypoint runs `alembic upgrade head` before uvicorn, which listens on `0.0.0.0`.
- **Reference data:** tariffs are seeded by an Alembic data migration (`op.bulk_insert`), never in `lifespan` or other app code. Price changes go in a new migration. Test fixtures insert tariffs themselves, since tests use `create_all` instead of migrations.
- **Tests need no external services:** the database is in-memory SQLite created by a fixture in `tests/conftest.py`, injected via `app.dependency_overrides`.
- **Settings:** `webhook_secret` is a `SecretStr` with no default. Never commit `.env`; add new variables to `.env.example`.
- **Errors:** validation errors use FastAPI's default 422 — no custom 422 handlers. Response bodies that differ from `{"detail": ...}` are returned with `JSONResponse`, not `HTTPException`.
- **Dates:** always timezone-aware UTC.
- **Dependencies:** use `Annotated[Type, Depends(...)]`, not `Depends(...)` as a default value. Reusable aliases live in `app/api/dependencies.py`.
- **`AI_LOG.md` is written by a human.** Don't create or edit it.
- **Never commit on the user's behalf.** Produce working-tree changes only.
